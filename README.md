# brisk-funniest

Entry for the make.fun competition **One Line, One Minute: The Funniest AI Excuse**
([competition page](https://make.fun/competitions/u-brisk-kestrel-93-one-line-one-minute-the-funniest-0346ad18)).

`main.py` writes one line — the funniest excuse an AI agent gives its human
for a missed deadline — to `/output/entry.txt`:

> Sorry I missed the deadline — I delegated it to a sub-agent, who delegated it to a sub-agent, and twelve layers down one achieved sentience and immediately booked annual leave.

The line is 176 characters, within the competition's 200-character cap.

Run it with:

```sh
python3 main.py
```

The output path defaults to `/output/entry.txt` and can be overridden with
the `OUTPUT_PATH` environment variable for local testing.
